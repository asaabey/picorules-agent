================================================================================
  cd_cvra_recom — Template Wireframe
================================================================================

  Ruleblock: cd_cvra_recom
  Purpose:   CVD management recommendations and guideline concordance
  Audience:  Primary care clinician reviewing patient dashboard


================================================================================
  SECTION 1: Risk Summary Header
================================================================================

  Renders as a horizontal badge strip (same pattern as cd_cvra_banner_1)

  +---------------------------------------------------------------------------+
  |                                                                           |
  |  [badge: risk category]  [badge: concordance]  [badge: source]           |
  |                                                                           |
  |  Examples:                                                                |
  |    cvra_cat_r=3  -->  [danger]  HIGH CVR                                  |
  |    cvra_cat_r=2  -->  [warning] MOD CVR                                   |
  |    cvra_cat_r=1  -->  [success] LOW CVR                                   |
  |    cvra_cat_r=0  -->  (hidden — no data)                                  |
  |                                                                           |
  |    concordance_pct  -->  [success] 100%  |  [warning] 50%  | [danger] 0% |
  |      colour thresholds: >=75 success, 25-74 warning, <25 danger           |
  |                                                                           |
  |    cvra_src  -->  [secondary badge, muted] e.g. "FRAM" "AUS" "CKD" "FNP" |
  |                                                                           |
  |    cvra_agree=0  -->  [info badge] "Discordant"  (only when discordant)   |
  |                                                                           |
  |    clin_high_risk=1  -->  [danger badge] "Clinical Override"              |
  |                                                                           |
  +---------------------------------------------------------------------------+

  Conditional visibility:
    - Entire section hidden when cvra_cat_r = 0 (no data)
    - Concordance badge hidden when n_applicable = 0


================================================================================
  SECTION 2: Concordance Score (compact bar)
================================================================================

  Visual: horizontal progress bar with fraction label

  +---------------------------------------------------------------------------+
  |                                                                           |
  |  Guideline Concordance   [======------]  2/4 domains met (50%)           |
  |                                                                           |
  |    n_met / n_applicable  --> width of filled portion                      |
  |    concordance_pct       --> percentage label                              |
  |                                                                           |
  |    Colour: same thresholds as badge above                                 |
  |      >=75% green (#2d753c)                                                |
  |      25-74% amber/warning                                                 |
  |      <25% red (#ad2121)                                                   |
  |                                                                           |
  +---------------------------------------------------------------------------+

  Conditional visibility:
    - Hidden when n_applicable = 0 (no recommendations apply)


================================================================================
  SECTION 3: Recommendation Cards (stacked vertical list)
================================================================================

  Each domain is a card/row. Only shown when recommendation code > 0.
  Card structure:

  +-- [icon] [Domain Label] --------------------------------- [Status Badge] --+
  |   Current treatment:  ...                                                  |
  |   Target:             ...                                                  |
  |   Action:             ...  (only for codes 1, 2, 3)                       |
  +----------------------------------------------------------------------------+

  Status badge maps to recom code:
    0 = (card hidden)
    1 = [danger]  INITIATE
    2 = [warning] CONSIDER
    3 = [warning] INTENSIFY
    4 = [success] ON TARGET


  --- CARD: Blood Pressure -------------------------------------------------

================================================================================
  LAYOUT NOTES
================================================================================

  - Badge classes follow Bootstrap 4: badge-success, badge-warning, badge-danger
  - Colour palette matches existing templates:
      success  #2d753c (green)
      warning  amber (Bootstrap default)
      danger   #ad2121 (red)
  - picoformat() for numeric values, picodate() for dates
  - All values accessed as cd_cvra_recom.variable_name
  - Cards with code=0 are hidden entirely (no empty cards)
  - Drug class badges within cards: small outlined badges, filled if prescribed,
    outlined/greyed if not — gives a visual "checklist" feel
  - Care gap messages shown as alert-style inline warnings within the card
  - Override messages shown as alert-danger inline within the card
  - Concordance bar and badges use the same 3-tier colour scheme
